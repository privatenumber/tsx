# Source maps

The NAPI transform exposes a boolean `sourcemap` option and returns a parsed v3 map object; it does not expose input-map, inline/external, output-filename, or `sourcesContent` controls ([options](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/src/transformer.rs#L162-L170), [public shape](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/index.d.ts#L29-L38)).

The builder uses the transform filename as its source and always records original source content ([builder](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_codegen/src/sourcemap_builder.rs#L66-L99), [compiler path](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc/src/compiler.rs#L319-L338)); original byte offsets and generated UTF-8 positions are converted to source-map UTF-16 columns ([original positions](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_codegen/src/sourcemap_builder.rs#L144-L160), [generated positions](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_codegen/src/sourcemap_builder.rs#L347-L356)).
