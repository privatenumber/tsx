# Configuration

Oxc accepts ES2015 through ES2026/ESNext and versioned engine targets such as `node24.15.0` ([ES targets](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_syntax/src/es_target.rs#L7-L45), [engine targets](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_compat/src/engine_targets.rs#L137-L173)). Before option overrides, unknown or query-bearing paths fall back to default JavaScript module parsing; `lang` restores TS/TSX language classification, while `sourceType` separately overrides parser module kind ([extension map](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_span/src/source_type.rs#L174-L216), [fallback](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_span/src/source_type.rs#L95-L100), [NAPI source type](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_napi/src/lib.rs#L63-L84)).

The NAPI transform receives only filename, source text, and explicit transform options; its public options expose no tsconfig input or discovery field ([options](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/index.d.ts#L446-L689), [transform path](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/src/transformer.rs#L894-L937)). JSX defaults to the automatic React runtime ([JSX defaults](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/jsx/options.rs#L8-L102)); legacy decorators/metadata and TypeScript class-field behavior require explicit options ([decorators](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/decorator/options.rs#L3-L44), [class fields](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/options.rs#L44-L86)). Import-elision option semantics are documented in [import elision](./import-elision.md).
