# CommonJS output

The NAPI transform exposes source language/module classification but no output-module option ([public options](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/index.d.ts#L446-L533)); NAPI conversion leaves the internal module option at its default `Preserve` value ([conversion](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/src/transformer.rs#L172-L217), [default](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/options/env.rs#L19-L30)). `sourceType: "commonjs"` changes parser rules, not ESM-to-CJS output ([source classification](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_napi/src/lib.rs#L63-L84)).

The TypeScript module pass lowers only `import = require()` and `export =`; it notes that general CommonJS insertion belongs to a future plugin ([implementation](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/module.rs#L25-L183)). Ordinary ESM imports, exports, re-exports, live bindings, and top-level await remain ESM syntax; CommonJS source classification can diagnose top-level await but does not lower it.
