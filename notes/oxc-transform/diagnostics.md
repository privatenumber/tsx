# Diagnostics

`transformSync()` and `transform()` return structured diagnostics alongside code instead of throwing transform failures ([result](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/src/transformer.rs#L34-L80), [sync/async paths](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/src/transformer.rs#L894-L1007)). Parser recovery can yield code with severity `Error`; transform warnings can yield runnable code, while semantic or transform errors can stop code generation ([pipeline](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc/src/compiler.rs#L127-L243)).

Diagnostics expose severity, message, labels, help, and a rendered codeframe; label offsets are UTF-8 byte offsets copied from Oxc spans ([public shape](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/index.d.ts#L10-L38), [conversion](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_napi/src/error.rs#L7-L96)). Invalid NAPI option values can throw before a transform result exists ([NAPI conversion](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/napi/transform/src/transformer.rs#L172-L217)).

Script/CommonJS parsing reports `import.meta` before later define replacement ([parser](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_parser/src/js/expression.rs#L674-L690), [diagnostic](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_parser/src/diagnostics.rs#L837-L840)); emitted code can therefore contain the replacement alongside a stale severity `Error`.
