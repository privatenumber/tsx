# Import elision

Oxc processes unused qualified import-equals aliases in reverse and reclassifies each root reference as type-only ([prepass](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/module.rs#L214-L285)); the default transform erases aliases without value references ([alias decision](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/module.rs#L104-L183)) and removes originating imports with no remaining value references ([import removal](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/annotations.rs#L100-L153), [reference predicate](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/annotations.rs#L628-L644)).

The inherited conformance input imports bindings referenced only as roots of import-equals aliases ([input](https://github.com/babel/babel/blob/ad572fd1a1615f53c4e3b85941760bdb1a1aefd9/packages/babel-plugin-transform-typescript/test/fixtures/imports/elide-type-referenced-in-imports-equal-no/input.ts#L1-L5)); Oxc overrides its output to `export {};` ([output](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/tasks/transform_conformance/overrides/babel-plugin-transform-typescript/test/fixtures/imports/elide-type-referenced-in-imports-equal-no/output.mjs#L1)). `onlyRemoveTypeImports: true` disables inferred cascading elision ([option](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/options.rs#L36-L43)); exported import-equals declarations remain runtime declarations ([decision](https://github.com/oxc-project/oxc/blob/c9d1a5b603ccacf21649ad41859ddeacb99e13bb/crates/oxc_transformer/src/typescript/module.rs#L104-L183)).
