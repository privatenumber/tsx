# Import elision

esbuild lowers qualified TypeScript import-equals declarations during parsing ([parse/lower](https://github.com/evanw/esbuild/blob/6ff1d8b0d8c134e867a397eef39702a223ebef9e/internal/js_parser/ts_parser.go#L1540-L1592)), binds imported roots as import identifiers ([binding](https://github.com/evanw/esbuild/blob/6ff1d8b0d8c134e867a397eef39702a223ebef9e/internal/js_parser/js_parser.go#L17060-L17097)), and removes unused aliases through TypeScript-specific analysis and a fixed-point pass for alias chains ([removal](https://github.com/evanw/esbuild/blob/6ff1d8b0d8c134e867a397eef39702a223ebef9e/internal/js_parser/js_parser.go#L17218-L17259), [fixed point](https://github.com/evanw/esbuild/blob/6ff1d8b0d8c134e867a397eef39702a223ebef9e/internal/js_parser/js_parser.go#L18624-L18688)).

Alias removal does not cascade to an originating external import: ignored JavaScript liveness leaves TypeScript use counts intact ([usage accounting](https://github.com/evanw/esbuild/blob/6ff1d8b0d8c134e867a397eef39702a223ebef9e/internal/js_parser/js_parser.go#L1732-L1766)), and import trimming consults those counts ([trimming](https://github.com/evanw/esbuild/blob/6ff1d8b0d8c134e867a397eef39702a223ebef9e/internal/js_parser/js_parser.go#L17290-L17435)).

Version 0.15.4 made qualified alias property accesses removable by general tree shaking ([commit](https://github.com/evanw/esbuild/commit/13587cef234e93658d938bc4d92b52b6aa386ef8), [tests](https://github.com/evanw/esbuild/blob/f4da27cb6c5907c333ab2cf09fa8bad4d928665f/internal/bundler/bundler_ts_test.go#L687-L748)); 0.18.17 made aliases rooted at imported bindings removable during TypeScript import analysis, so their removal no longer required tree shaking ([commit](https://github.com/evanw/esbuild/commit/af2bc58e2790932578df6f2edf287a70e7496d93), [issue](https://github.com/evanw/esbuild/issues/3271)).
