# Import elision

`import Alias = Namespace.Member` is an internal `ImportEqualsDeclaration` with a qualified-name module reference, distinct from `import Alias = require("module")` ([parser](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/parser.ts#L8384-L8422), [AST](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/types.ts#L3663-L3688)); the binder declares the local `Alias` as an alias symbol ([binder](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/binder.ts#L3047-L3053)).

Alias links record whether a symbol is referenced as an emit-capable value ([state](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/types.ts#L6058-L6073)); type references do not mark runtime liveness ([type references](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/checker.ts#L17370-L17403)), while value references propagate through an internal alias to its leftmost RHS identifier ([propagation](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/checker.ts#L30834-L30854)).

Default JavaScript emit removes an unreferenced internal alias ([import-equals transform](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/transformers/ts.ts#L2415-L2484)) and removes originating import specifiers with no runtime references ([import transform](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/transformers/ts.ts#L2259-L2321)); an emptied import is removed rather than rewritten as a side-effect import.

`transpileModule()` creates a one-file program with `noCheck`, `noResolve`, and `isolatedModules` ([pipeline](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/services/transpile.ts#L54-L65)); the emitter's reference prepass supplies the local binding/reference analysis needed for the same cascading elision without imported declaration resolution ([prepass](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/emitter.ts#L836-L846)).

Unused and type-only qualified aliases suppress the originating module's side effects. For value-backed targets or one-file/no-check emit, runtime-used aliases retain the import and emit `var Alias = Root.Member`, while `export import Alias = Root.Member` emits a value export ([qualified transform](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/transformers/ts.ts#L2411-L2484)). Whole-program checking can diagnose a declaration-only target and erase the alias/import, including invalid runtime/exported uses ([checks](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/checker.ts#L48470-L48500)).

`verbatimModuleSyntax` preserves non-`type` imports and qualified aliases as runtime intent ([predicate](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/transformers/ts.ts#L2747-L2749)); type-only targets receive TS1484/TS1288 diagnostics but still emit unless `noEmitOnError` suppresses output ([checks](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/checker.ts#L48470-L48499), [emit gate](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/program.ts#L5072-L5095)).

Global scripts preserve a top-level qualified value alias even when it is used only as a type; making the file an external module enables normal elision ([script special case](https://github.com/microsoft/TypeScript/blob/637d5746b70257028fb95aad32ddec6b26ab0a14/src/compiler/transformers/ts.ts#L2411-L2422)).
